# NovaQuest Arena

A static browser prototype: play mini-games, earn demo coins, complete quests, and use Studio to create simple playable mini-games.

## Owner admin panel

Join using your owner demo account (enter the owner email in the email field) to show the Admin navigation and panel. Enter a player username, then choose Gift coins, Set balance, Ban player, or Unban player. Coin amounts are required only for coin actions; ban actions do not depend on the amount field. Enter a reason if desired. The role directory shows accounts that have joined in this browser, and actions appear in the local audit list.

## Important security warning

This is strictly a local browser demo. The email check is not verified authentication, anyone can enter an email, and browser storage can be edited. Admin changes affect only this browser and are not shared with players. Do not use the panel for real accounts, bans, or currency. A production admin panel requires verified server-side authentication, role checks, a database, and a moderation audit log.

## Studio and games

Studio lets players build and publish games using tap, target, or quiz templates. Published games and progress are stored only in the current browser.
